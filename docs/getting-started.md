# Getting Started

Welcome to CustomCrafting! This guide will help you get started with the system.

## Overview
CustomCrafting allows you to define custom recipes for almost any operation in Minecraft, from simple crafting to complex cooking and smithing.

## Key Steps
1. **Understand the Core Concepts**: Read the [Introduction](#) and [Common Properties](#) pages.
2. **Explore Recipe Types**: Look into [Crafting](#), [Cooking](#), [Mixing](#), [Grinding](#), [Smithing](#), and [Repairing](#).
3. **Define your Recipes**: You can define your recipes in HOCON or JSON format.
4. **Test and Refine**: Use the editor and the system's logging to test your recipes.
